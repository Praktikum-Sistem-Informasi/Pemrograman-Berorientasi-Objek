## 🛠️ Persiapan & Cara Penggunaan

```bash
# 1. Pastikan JDK 26+ dan Apache NetBeans IDE sudah terinstall
java -version

# 2. Clone repository ini
git clone [https://github.com/username/Praktikum-PBO-Java.git](https://github.com/username/Praktikum-PBO-Java.git)

# 3. Buka Apache NetBeans IDE
# 4. Pilih File -> Open Project -> Arahkan ke folder contoh_kode/

```

**Kebutuhan Minimum**:

* [Java Development Kit (JDK 26 atau lebih baru)](https://www.codelerity.com/netbeans/)
* [Apache NetBeans IDE (v30+)](https://www.codelerity.com/netbeans/)
* [Laragon](http://laragon.org/download) / [XAMPP](https://www.apachefriends.org/download.html)
* [Git (Latest Update)](https://git-scm.com/install/)
